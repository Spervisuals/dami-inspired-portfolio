# Dami Osoba–style portfolio homepage

## Goal
Build the first portfolio screen as a close visual recreation of the supplied reference: a dark dashboard-style page with a fixed side menu and a large geometric introduction panel.

## What I’ll build
- A desktop homepage with the left profile sidebar, highlighted Home item, navigation links, and contact panel.
- A large dark hero panel with custom monochrome geometric artwork, the same headline hierarchy, and matching spacing and typography.
- Mobile and tablet adaptations where the menu remains easy to open and use.
- Working navigation that moves to the relevant homepage sections while keeping this first version focused on the home layout.
- Page title and sharing description specific to the portfolio.

## Visual system
- Near-black page and panels, subtle gray borders, white typography, and muted gold accents.
- Editorial serif display type paired with a clean sans-serif interface type.
- Tight corner radii and restrained transitions matching the reference.

## Review
- Check the live homepage at desktop and mobile sizes.
- Confirm the menu works and no content overlaps or clips.
- Leave the page ready for your next round of name, biography, contact, and project-content changes.
